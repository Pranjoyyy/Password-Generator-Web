A modern Password Generator built using HTML, CSS and JavaScript.

## ✨ Features

- Generate secure passwords
- Adjustable password length (8–50)
- Include numbers
- Include symbols
- Password strength meter
- Show / Hide password
- Copy password to clipboard
- Responsive glassmorphism UI

## 🛠 Built With

- HTML5
- CSS3
- JavaScript
